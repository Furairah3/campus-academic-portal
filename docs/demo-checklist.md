# 3–5 minute demonstration

1. **0:00–0:40 — Introduce the accounts.** Explain that S1, S2 and L1 are fictional and L1 is assigned IS451.
2. **0:40–1:30 — Passkey.** Enroll S1 with its one-time code and sign in with the device passkey. Point out that the browser response is verified by the server.
3. **1:30–2:20 — Ownership.** Show S1's grades, then request S2's record directly and show that the API denies it.
4. **2:20–3:20 — Lecturer policy.** Sign in as L1, update a grade, refresh, and show persistence. Explain the course-assignment check.
5. **3:20–4:10 — Protected academic note.** Encrypt the sample note, decrypt it, then test integrity protection and show the altered data was rejected.
6. **4:10–5:00 — Close with limitations.** Mention classroom codes, local SQLite, key/session limits and that the prototype is not production-ready.
